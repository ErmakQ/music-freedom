# Музыкальная полка

Соберите любимый плейлист в один ZIP-архив. Добавьте список треков, проверьте найденные композиции и скачайте готовый файл.

## Скачать и установить

[**Скачать Музыкальную полку для Windows**](../../releases/latest/download/music-shelf-setup.exe)

1. Скачайте и откройте файл `music-shelf-setup.exe`.
2. Пройдите установку. Папку программы можно оставить по умолчанию.
3. Откройте **«Музыкальную полку»** через ярлык на рабочем столе или в меню «Пуск».

После запуска откроется рабочая страница в браузере. Когда архив будет готов, браузер сохранит его в обычную папку «Загрузки».

## Как собрать архив

1. Добавьте плейлист: вставьте список треков, загрузите `.txt`, `.m3u` или `.m3u8`, укажите ссылку на Яндекс Музыку либо выберите сохранённую HTML-страницу плейлиста.
2. Проверьте список перед запуском: уберите лишнее, при необходимости измените порядок.
3. Запустите обработку.
4. Посмотрите треки, которым нужна проверка, и подтвердите или отклоните их.
5. Скачайте готовый ZIP-архив.

Для большого плейлиста Яндекс Музыки лучше открыть его в браузере, прокрутить до конца, сохранить страницу как HTML и загрузить этот файл в приложение.

## Что умеет приложение

- принимает текстовые списки, `.txt`, `.m3u`, `.m3u8`, ссылки, iframe и HTML-страницы плейлистов;
- помогает привести список в порядок до запуска;
- ищет подходящие версии треков и показывает спорные совпадения;
- позволяет вручную решить, какие треки включить в архив;
- собирает ZIP только из подтверждённых композиций.

Яндекс Музыка используется только для списка и метаданных треков. Аудио из Яндекс Музыки приложение не скачивает.
