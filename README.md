# Музыкальная полка

Windows-приложение, которое помогает собрать ZIP-архив из треков плейлиста: загрузите список, проверьте найденные композиции и скачайте готовый архив.

## Установка

Пользователю не нужны Python, Node.js, браузерные расширения или какие-либо команды.

1. Скачайте [установщик для Windows](https://github.com/ErmakQ/music-freedom/releases/latest/download/music-shelf-setup.exe).
2. Запустите `music-shelf-setup.exe` и выберите папку для программы, если стандартная не подходит.
3. После установки откройте ярлык **«Музыкальная полка»**.

Если прямая ссылка не открылась, файл также доступен в разделе [Releases](../../releases) этого репозитория.

Приложение само откроет страницу в браузере. Закрыть его полностью можно через значок в системном трее рядом с часами.

Готовые ZIP-архивы скачиваются браузером в обычную папку «Загрузки». При необходимости её можно изменить в настройках браузера.

## Как пользоваться

1. Добавьте список треков: вставьте текст, загрузите `.txt`, `.m3u` или `.m3u8`, укажите ссылку или iframe Яндекс Музыки либо загрузите сохранённую HTML-страницу плейлиста.
2. Проверьте список до запуска: удалите лишнее и при необходимости измените порядок.
3. Нажмите запуск обработки.
4. Просмотрите треки, которым нужна ручная проверка, и подтвердите или отклоните их.
5. Скачайте итоговый ZIP-архив.

Для большого плейлиста Яндекс Музыки надёжнее открыть его в браузере, прокрутить до конца, сохранить страницу как HTML и загрузить этот файл в приложение.

## Возможности

- импорт текста, `.txt`, `.m3u`, `.m3u8`, ссылок, iframe и HTML-страниц плейлистов;
- предварительная очистка и редактирование списка;
- поиск кандидатов и оценка совпадений;
- ручная проверка спорных треков;
- ZIP-архив только с принятыми треками;
- отчёты по найденным, отклонённым и проблемным композициям.

Важно: Яндекс Музыка используется только для получения списка и метаданных треков. Аудио из Яндекс Музыки приложение не скачивает.

### Режимы поиска

- `fast` — быстрый HTTP-first поиск без Selenium.
- `balanced` — основной режим по умолчанию, HTTP-поиск плюс кэш.
- `deep` — более медленный режим с разрешённым Selenium fallback.

Google Chrome нужен только для режима `deep` или если явно включён `ENABLE_SELENIUM_FALLBACK=true`.

### Файлы результатов

После прогона могут быть доступны:

- `quality_report.json` и `quality_report.csv`;
- `manual_review.csv`;
- `candidates.json`;
- `downloaded.log`;
- `run_info.txt`;
- папки `accepted/` и `rejected/`;
- `result.zip`.

В итоговый архив попадают только треки со статусом `OK`.

<details>
<summary><strong>Сборка EXE для разработчика</strong></summary>

Эти шаги не нужны обычному пользователю. Они требуются только для создания новой версии установщика из исходного кода.

Нужны Python `3.10+`, Node.js `18+` и Inno Setup 6 для создания установщика:

```powershell
.\.venv\Scripts\python.exe build_exe.py
```

Скрипт сам устанавливает сборочные зависимости, собирает frontend и создаёт:

- `release\music-shelf-windows.zip` — переносимая EXE-сборка;
- `dist\MusicShelf\MusicShelf.exe` — приложение до упаковки установщиком;
- `release\music-shelf-setup.exe` — установщик, если установлен Inno Setup 6.
</details>

<details>
<summary><strong>Ручной запуск и настройки для разработки</strong></summary>

Установка backend-зависимостей:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
```

Установка frontend-зависимостей:

```bat
cd frontend
npm install
cd ..
```

Запуск backend:

```bat
.venv\Scripts\python -m uvicorn web.app:app --host 127.0.0.1 --port 8000
```

Запуск frontend dev-сервера:

```bat
cd frontend
npm run dev
```

Пример настроек лежит в [`.env.example`](.env.example). Часто используются `SEARCH_MODE`, `ENABLE_SELENIUM_FALLBACK`, `SEARCH_CACHE_ENABLED`, `HTTP_SEARCH_CONCURRENCY`, `DOWNLOAD_CONCURRENCY` и `MAX_CONCURRENT_JOBS`.

Основные части проекта:

- [web/app.py](web/app.py) — FastAPI backend и web API;
- [frontend/src/App.tsx](frontend/src/App.tsx) — React-интерфейс;
- [downloader_core.py](downloader_core.py) — поиск и скачивание;
- [quality.py](quality.py) — проверка качества;
- [README_OVERVIEW.md](README_OVERVIEW.md) — технический обзор.

Перед pull request выполните:

```bat
python -m unittest
cd frontend
npm run build
```
</details>
