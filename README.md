# music-freedom

Простое локальное веб-приложение, которое помогает собрать музыкальный архив из плейлиста.

Вы даёте список треков, приложение ищет подходящие mp3-файлы, скачивает найденное, проверяет совпадения и собирает результат в ZIP-архив.

## Коротко

Что можно загрузить:

- обычный текстовый список треков;
- `.txt`-файл;
- ссылку или iframe Яндекс Музыки;
- сохранённую HTML-страницу плейлиста.

Что получится на выходе:

- архив с найденными треками;
- отчёты о том, что скачалось, что не нашлось и что требует ручной проверки.

## Запуск для чайников

Самый простой способ на Windows:

```bat
start.bat
```

Запустите этот файл двойным кликом или из папки проекта.

Что он делает сам:

1. создаёт файл настроек `.env`, если его ещё нет;
2. проверяет, установлен ли Python;
3. если Python не найден, скачивает официальный Python `3.11.9` и ставит его локально в папку `.runtime\python`;
4. создаёт виртуальное окружение `.venv`;
5. устанавливает нужные Python-зависимости;
6. запускает приложение;
7. открывает браузер по адресу `http://127.0.0.1:8000`.

На компьютере должен быть установлен Google Chrome. Он нужен для поиска и скачивания через Selenium.

## Как передать программу на другой ПК

На своём компьютере запустите:

```bat
prepare_release.bat
```

Скрипт соберёт готовый архив:

```text
release\music-freedom-release.zip
```

Дальше:

1. перенесите этот ZIP на другой Windows-ПК;
2. распакуйте его;
3. запустите `start.bat`;
4. дождитесь открытия браузера.

Если архив подготовлен через `prepare_release.bat`, на другом ПК не нужен Node.js. Python тоже не обязателен: `start.bat` скачает его сам, если не найдёт установленный.

## Как пользоваться

### Обычный список треков

Вставьте строки в формате:

```text
Artist - Title
Artist - Title
Artist - Title
```

Или загрузите `.txt`-файл с таким же списком.

### Плейлист из Яндекс Музыки

Можно использовать:

- ссылку на плейлист;
- iframe-код;
- сохранённый HTML-файл страницы плейлиста.

Для большого плейлиста лучше всего:

1. открыть плейлист в браузере;
2. прокрутить страницу до конца;
3. сохранить страницу как HTML;
4. загрузить HTML-файл в приложение;
5. проверить список треков перед запуском.

Важно: приложение не скачивает музыку из Яндекс Музыки. Яндекс Музыка используется только как источник списка треков.

## Что важно знать

- Приложение не гарантирует, что найдёт все треки.
- Иногда попадаются неподходящие версии: remix, live, clean, radio edit и похожие варианты. Приложение старается их отфильтровать.
- Некоторые треки могут попасть в ручную проверку.
- Источники mp3 могут быть нестабильными.
- Сохранённая HTML-страница плейлиста может содержать личные данные профиля. Не публикуйте такие файлы.

Проект не предназначен для обхода DRM, paywall, авторизации, антибот-защиты или региональных ограничений.

## Ручной запуск для разработки

Этот раздел нужен, если вы хотите менять код проекта.

Понадобится:

- Python `3.10+`;
- Node.js `18+`;
- Google Chrome.

Установка Python-зависимостей:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
```

Установка frontend-зависимостей:

```bat
cd frontend
npm install
cd ..
```

Запуск backend:

```bat
py -m uvicorn web.app:app --host 127.0.0.1 --port 8000
```

Запуск frontend в отдельном терминале:

```bat
cd frontend
npm run dev
```

После этого откройте адрес, который покажет Vite. Обычно это:

```text
http://localhost:5173
```

## Сборка интерфейса

Если нужно собрать frontend заранее:

```bat
cd frontend
npm run build
```

Собранные файлы появятся в:

```text
frontend\dist
```

После этого приложение можно запускать одним backend-сервером на `http://127.0.0.1:8000`.

## Настройки

Основные настройки лежат в `.env`.

Если файла нет, `start.bat` создаст его из `.env.example`.

Обычно ничего менять не нужно. Настройки могут понадобиться, если вы хотите изменить лимиты, количество параллельных загрузок, источники поиска или параметры Selenium.

## Основные файлы проекта

- `start.bat` — простой запуск приложения;
- `prepare_release.bat` — сборка ZIP-архива для переноса;
- `web/app.py` — backend API;
- `frontend/` — интерфейс;
- `downloader_core.py` — поиск и скачивание;
- `quality.py` — проверка качества совпадений;
- `playlist_importers/` — импорт плейлистов из текста, ссылок, iframe и HTML.

## Ответственное использование

Используйте проект только в рамках законного доступа к источникам. Не публикуйте свои `.env`, скачанную музыку, сохранённые HTML-страницы с личными данными и другие локальные файлы.
